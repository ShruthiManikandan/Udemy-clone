# Udemy Clone

A simple **Udemy-inspired online learning website** developed using **HTML and CSS**. The project focuses on recreating the basic structure and user interface of an online course platform.

## Pages

* **Home Page** – Displays the navigation bar, search section, course categories, and recommended courses.
* **Courses Page** – Displays available courses in a card-based layout.
* **Course Details Page** – Shows information about a selected course.


## Technologies Used

* HTML5
* CSS3

## How to View

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Navigate through the available pages using the links on the website.

### Run with VS Code

You can also open the project in **Visual Studio Code** and use the **Live Server** extension to view the website in your browser.

## Project Purpose

This project was created to practice **HTML and CSS fundamentals**, including page structure, navigation, layouts, images, styling, and basic responsive design.
